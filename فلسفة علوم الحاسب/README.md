# فلسفة العلم؟

أي علم(مقرر) بتتعلمه **بتطبيقاته**(أكاديمي من دون توضيح الغاية من المقرر أو حل مسائل/أسئلة عشان الإمتحان) فقط متعرفش هو اتعمل ليه؟ وتاريخه أيه؟ وفلسفة العلم أيه؟ فأنت يعتبر متعلمتش  (**مفهمتش فهم حقيقي**) حاجة عن العلم.

# لماذا فلسفة العلم؟
مقررات كتير هتدرسها **ومش هتبقى عارف ليه بتدرسها** ومحتاج حافز يفهمك نبذه عن العلم أو بمعنى تاني **فلسفة العلم** عشان تقدر تلمس فعلاً تطبيقات المقرر دا على أرض الواقع وأهميته أيه؟ وعلاقتك مع المقرر هتبقى أكبر من إمتحان أكاديمي في أخر السنة.
