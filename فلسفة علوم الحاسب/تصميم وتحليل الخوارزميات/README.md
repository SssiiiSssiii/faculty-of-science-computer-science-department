# خوازمية إقليدس
الوصف: لدينا عددان طبيعيان `س` و`ص`، أوجد القاسم المشترك الأكبر لهم، **أي أكبر عدد طبيعي الذي يقسم `س` و`ص` معاً من دون أي باقٍ من القسمة**.
